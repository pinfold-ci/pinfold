# 0000. Record architecture decisions

- **Status:** accepted
- **Date:** 2026-10-30

## Context

Pinfold makes security promises. Contributors and users need to know *why* the design is the way it is, especially where a simpler option was rejected.

## Decision

Non-obvious technical decisions are recorded as short Architecture Decision Records (Michael Nygard's format) in `docs/adr/NNNN-title.md`: context, decision, consequences. Changes to the guarantees in design §2 always get an ADR.

## Consequences

Decisions can be reviewed later without asking the people who made them. Superseded ADRs are kept and marked as superseded.
