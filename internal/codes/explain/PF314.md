# PF314: Job depends on a gated job without its own gate

The job `needs:` a job whose `if:` requires `maintainer: true`. When the gate denies, the gated job's steps are skipped, but the job itself still succeeds, so GitHub runs this job anyway: for anyone who can fire the trigger, such as any commenter. If this job releases, labels or comments, the maintainer gate protects nothing.

This is an error: a `needs:` on a gated job looks like protection but isn't.

## How to fix it

Add `{ maintainer: true }` to this job's `if:` too, so it gets its own gate.
