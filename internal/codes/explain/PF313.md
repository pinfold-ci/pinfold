# PF313: Step not allowed under pull_request_target

Workflows on `pull_request_target` run with the base repository's credentials while reacting to pull requests from forks. Pinfold allows only the label and comment effects there (`add_labels`, `remove_labels`, `comment`), with conditions on PR metadata: no checkout, no scripts, no other actions.

## How to fix it

Move other work to a `pull_request` workflow (untrusted builds arrive in v0.2), or keep this workflow to labelling and commenting.
