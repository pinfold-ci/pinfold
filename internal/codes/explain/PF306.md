# PF306: Input not supported by a pinned container

Some actions don't meet Pinfold's rule for credential-holding jobs (for example, they build from a floating base image), so Pinfold runs the action's published image pinned by its digest instead. Only the inputs the registry maps for that image are supported, so nothing you write is silently ignored.

## How to fix it

Remove the input, or use one of the inputs listed in the hint. If you need another input, open an issue so it can be reviewed and added to the registry.
