# PF303: Checkout override in a privileged context

In a privileged workflow or job, `actions/checkout` must check out the trusted ref without persisting credentials. Overriding `repository` or `ref` (for example to a pull request's head) checks out code the base repository doesn't vouch for, the classic "pwn request". `allow-unsafe-pr-checkout` and `persist-credentials` are forbidden for the same reason.

## How to fix it

Remove the input. Use the `checkout: {}` step, which Pinfold generates safely. To act on a pull request's contents, use an unprivileged workflow.
