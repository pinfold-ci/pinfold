# PF910: Internal error: cache restore in a privileged or feeder job

A generated job that holds credentials, or feeds one through artifacts or outputs, restores a cache (design §2). The compiler's trust-zone checks should have prevented this.\n\nThis is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the workflow with `pinfold compile`. If the problem stays, report it (see SECURITY.md) and don't use the generated output.
