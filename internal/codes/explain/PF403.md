# PF403: Read permission beyond contents in an unprivileged job

An unprivileged job runs your scripts and third-party actions, so it may be running code an attacker influenced. Design §4 limits such a job to `contents: read`. This job declares another read scope (for example `packages`, `security-events`, `pull-requests` or `actions`).

## How to fix it

Remove the permission. If a step really needs it, move that step to a privileged job, which can't run your scripts, and pass data between the jobs with `produces`/`consumes`.
