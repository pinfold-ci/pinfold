# PF203: Untrusted value passed to an action input

An untrusted value is passed in `with:`. Some actions evaluate inputs as code or use them in shell commands (for example `actions/github-script`'s `script`), so Pinfold never puts untrusted data in `with:`, with no exceptions (design §2).

## How to fix it

Pass the data to a `run:` step through a `T_*` environment variable, or use an effect, which handles untrusted input safely.
