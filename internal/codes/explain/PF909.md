# PF909: Internal error: user code in a privileged job

A generated job that holds credentials contains a `run:` step or an action that isn't `privileged_ok` (design §2, first row), and the workflow doesn't set `unsafe_run`; or it sets `unsafe_run` and the file isn't stamped with it. The compiler's trust-zone checks should have prevented this.\n\nThis is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the workflow with `pinfold compile`. If the problem stays, report it (see SECURITY.md) and don't use the generated output.
