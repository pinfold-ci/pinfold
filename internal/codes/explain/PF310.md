# PF310: unsafe_run turns guarantees off

The workflow sets `unsafe_run: true`, so Pinfold doesn't enforce trust zones for it (user scripts and unreviewed actions are allowed in jobs that hold credentials). The generated file is stamped with this, and `pinfold-verify` treats adding it as a security-relevant change.

## How to fix it

Prefer splitting the work so that privileged jobs only run effects and reviewed actions; then remove `unsafe_run`.
