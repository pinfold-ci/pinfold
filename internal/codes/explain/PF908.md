# PF908: Internal error: artifact download without binding

In a job that holds credentials, every artifact download must come right after Pinfold's generated check that the run holds exactly the artifact the producing job reported (same id and digest). The generated workflow has a download without it.\n\nThis is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the workflow with `pinfold compile`. If the problem stays, report it (see SECURITY.md) and don't use the generated output.
