# PF401: Missing permission

A step needs a token permission the job doesn't declare: `checkout` needs `contents: read`, each effect and registry action has fixed requirements, listed in the message. Pinfold doesn't add permissions for you (they're declared, never inferred), so the job's token has exactly what you wrote.

## How to fix it

Add the permission named in the hint to the job's `permissions:`. For comments and labels, either `issues: write` or `pull-requests: write` works; use the one that matches what the job acts on.
