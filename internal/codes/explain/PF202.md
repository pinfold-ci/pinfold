# PF202: Untrusted value in an environment variable not named T_*

An untrusted value (event data such as a title, branch name or comment, any job output, or a repository variable) is passed to a step in an environment variable whose name doesn't start with `T_`. Pinfold passes untrusted data only through `env:`, which is safe from injection, and requires the `T_` prefix so that whoever writes or reviews the script can see which variables are untrusted and must be quoted and validated.

## How to fix it

Rename the variable, for example `TITLE` to `T_TITLE`, and quote it in the script (`"$T_TITLE"`).
