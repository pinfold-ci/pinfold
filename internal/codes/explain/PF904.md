# PF904: Internal error: expression in a forbidden place

A generated workflow contains `${{ ... }}` somewhere Pinfold never puts one: in a `run:` script, in a `with:` value (other than an allowed, untainted value), or outside steps. Expressions there are how untrusted text gets injected into code, so the verifier treats any of them as a compiler bug (design §2).

## How to fix it

Please report it (see SECURITY.md). Don't use the generated output.
