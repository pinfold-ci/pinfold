# PF906: Internal error: unrecognised script in a privileged job

A job that holds credentials contains an `actions/github-script` step that isn't one of Pinfold's generated effect steps: it isn't marked as generated, or its script differs from every script the compiler generates. Pinfold only runs its own literal effect scripts in privileged jobs.\n\nThis is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the workflow with `pinfold compile`. If the problem stays, report it (see SECURITY.md) and don't use the generated output.
