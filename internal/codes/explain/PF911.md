# PF911: Internal error: feeder or privileged job on a runner that may not be fresh

The verifier found a generated feeder or privileged job whose `runs-on` isn't a standard GitHub-hosted runner, and the spec's `ephemeral_runner: true` assertion isn't stamped in the file header (security audit D1). The compiler should have reported PF315 instead.

This is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the file with `pinfold compile`. If the error remains, please report it with your spec.
