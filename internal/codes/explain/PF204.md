# PF204: Secret passed to an input that isn't a secret input

A secret is passed to an action input that the registry doesn't list as a secret input for that action, or the action isn't in the registry. Secrets should only go where the action expects a credential, not into inputs that may be logged or forwarded.

## How to fix it

Pass the secret to one of the action's secret inputs (listed in the hint), or through `env:` to a `run:` step in an unprivileged job.
