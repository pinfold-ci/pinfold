# PF311: pull_request_target may be blocked

GitHub blocks workflows triggered by `pull_request_target` by default in public repositories from 2026-12-02, unless an Actions event policy allows the event. The workflow compiles, but it may never run.

## How to fix it

Keep it for private repositories, or add an Actions event policy that allows `pull_request_target`. Pinfold's own verification doesn't need this trigger.
