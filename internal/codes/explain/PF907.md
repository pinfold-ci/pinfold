# PF907: Internal error: maintainer gate missing or bypassable

A job whose condition includes `maintainer: true` must start with Pinfold's generated gate step (`id: pinfold_gate`), and every later step must run only when the gate passed (`if: steps.pinfold_gate.outputs.ok == 'true'`). The generated workflow doesn't have that shape.\n\nThis is a bug in Pinfold (or the generated file was edited), not in your spec.

## How to fix it

Regenerate the workflow with `pinfold compile`. If the problem stays, report it (see SECURITY.md) and don't use the generated output.
