# PF905: Internal error: container image not pinned by the registry

A generated step uses a `docker://` image that isn't a registry-listed image pinned by its sha256 digest. Pinfold only ever emits digest-pinned images it has reviewed.\n\nThis is a bug in Pinfold, not in your spec.

## How to fix it

Please report it (see SECURITY.md). Don't use the generated output.
