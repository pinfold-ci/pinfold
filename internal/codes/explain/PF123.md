# PF123: Invalid action reference

`uses:` must be `owner/repo@tag` or `owner/repo/path@tag`. Bare commit SHAs, branches, `docker://` images and local `./` actions aren't accepted: Pinfold pins every action to a commit SHA itself and records it in `pinfold.lock`.

## How to fix it

Reference a release tag, such as `actions/checkout@v7`. `pinfold lock` resolves it to a commit.
