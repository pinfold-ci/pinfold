# PF102: Forbidden YAML feature

The spec uses an anchor (`&name`), alias (`*name`), merge key (`<<`) or explicit tag (`!!str`, `!custom`).

Pinfold accepts a restricted subset of YAML. Anchors, aliases and merge keys are a form of templating: they make it harder to see what a job really contains, and aliases can be abused to make a tiny file expand enormously. Tags change how values are interpreted.

## How to fix it

Write the value out in full at each place it's used. If you're repeating a lot, that's a sign the spec could be simpler, or a feature request.
