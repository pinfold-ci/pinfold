# PF901: Internal error: workflow permissions aren't empty

The verifier re-reads every generated workflow and found that the workflow-level `permissions:` isn't `{}`. Pinfold always emits `permissions: {}` at workflow level and grants permissions per job (design §2).

This is a bug in Pinfold, not in your spec.

## How to fix it

Please report it (see SECURITY.md): include the spec and the compiler version. Don't use the generated output.
