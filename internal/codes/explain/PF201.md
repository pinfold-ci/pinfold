# PF201: `${{` isn't allowed in the spec

The spec contains `${{`. Raw GitHub expressions are how untrusted data (titles, branch names, comments) gets injected into scripts, so Pinfold doesn't accept them anywhere. Values come from typed sources instead.

## How to fix it

Use a typed value: `{ context: issue.number }`, `{ secret: NAME }`, `{ var: NAME }` or `{ output: job.name }`. The compiler decides how each one may be used safely.
