# Getting help

Pinfold is pre-alpha and maintained by a small team. Here is where to go:

| You want to… | Go to |
|---|---|
| Ask how to do something, or why Pinfold rejects a spec | [Discussions → Q&A](https://github.com/pinfold-ci/pinfold/discussions/categories/q-a). Run `pinfold explain <code>` first: every diagnostic has a page. |
| Report a bug (wrong output, a crash, a misleading message) | [Open an issue](https://github.com/pinfold-ci/pinfold/issues/new/choose) with the spec, the command and the output. |
| Suggest a feature or a new action for the registry | [Discussions → Ideas](https://github.com/pinfold-ci/pinfold/discussions/categories/ideas), or a feature issue if it's small and concrete. |
| Propose a change to the spec language, trust zones, taint, the verifier, the lock or the guarantees | An [RFC in Discussions](https://github.com/pinfold-ci/pinfold/discussions/categories/rfcs) (see [GOVERNANCE.md](GOVERNANCE.md)). |
| Report a security problem | **Privately**, as described in [SECURITY.md](SECURITY.md). Please don't open a public issue. |

## What to expect

- Questions and issues are read at least weekly. There is no guaranteed response time for support.
- Security reports are acknowledged within 5 working days ([SECURITY.md](SECURITY.md)).
- Only the latest commit on `main` (and, after v0.1, the latest release) is supported.

There is no paid support.
